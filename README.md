# Contest Bot — Telegram-бот для конкурсов

## Стек
Python 3.11+, aiogram 3, Vercel (serverless, webhook-режим), Supabase (Postgres).

## Деплой

### 1. Supabase
1. Создай проект на supabase.com.
2. В SQL Editor выполни содержимое `sql/schema.sql`.
3. Settings → Database → Connection string → скопируй **Connection pooling** строку
   (режим Transaction, порт обычно 6543) — это и есть `DATABASE_URL`.

### 2. Telegram
1. Создай бота через @BotFather, получи `BOT_TOKEN`.
2. Узнай свой user_id (например, через @userinfobot) — это `ADMIN_ID`.

### 3. Vercel
1. `vercel link` в папке проекта, затем `vercel env add` для каждой переменной:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `DATABASE_URL`
   - `CRON_SECRET` (любая случайная строка, для защиты cron-эндпоинта)
2. Deploy: `vercel --prod`

### 3.1. Финализация конкурсов (внешний cron)
Встроенные Vercel Cron Jobs на Hobby-плане запускаются не чаще раза в сутки — этого мало для
своевременного подведения итогов. Вместо этого используем бесплатный внешний планировщик:

1. Зарегистрируйся на [cron-job.org](https://cron-job.org) (или аналог, например EasyCron).
2. Создай задачу:
   - URL: `https://<твой-домен>.vercel.app/api`
   - Метод: GET
   - Периодичность: каждые 15 минут
   - Заголовок: `Authorization: Bearer <значение CRON_SECRET>`
3. Готово — сервис сам будет дёргать эндпоинт, `CRON_SECRET` защищает его от посторонних вызовов.

### 4. Установка вебхука
После деплоя выполни один раз (замени значения):

```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<твой-домен>.vercel.app/api"
```

Обрати внимание: и вебхук Telegram, и крон-джоб указывают на **один и тот же URL** — `/api`.
Они различаются HTTP-методом: Telegram всегда шлёт `POST` (апдейты), крон дергает `GET` (финализация).

## Как пользоваться

- `/admin` — меню администратора (доступно только ADMIN_ID)
- `/new_contest` — пошаговое создание конкурса (название → описание → дедлайн → призы по местам → условия)
- `/contests` — список конкурсов и реф-ссылок

Реф-ссылка на конкретный конкурс выдаётся автоматически после создания:
`https://t.me/<бот>?start=c_<ref_code>`

## Что уже реализовано
- Создание конкурса с произвольным числом призовых мест и вместимостью на каждое (число или "без ограничений")
- Условия двух типов: автопроверка подписки на канал (бот должен быть админом канала) и проверка по скриншоту (уходит тебе в личку на одобрение/отклонение)
- Уведомление участнику при выполнении всех условий
- Автоматическая финализация по cron: раскладка подтверждённых участников по местам согласно вместимости, рассылка результатов

## Что стоит доделать дальше
- Редактирование/удаление уже созданных конкурсов
- Статистика по конкурсу (сколько подтверждено / на проверке / отклонено)
- Ограничение на повторный переход по чужой реф-ссылке одним юзером на разные конкурсы (сейчас это уже покрыто — один юзер = одна запись на конкурс)
- Красивое форматирование дедлайна с учётом часового пояса пользователя
